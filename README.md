# 💳 Smart ATM System (Java Console Project)

## 📌 Overview
This is a console-based ATM simulation system built using Java. It demonstrates Object-Oriented Programming concepts like encapsulation, classes, and objects.

## 🚀 Features
- PIN-based authentication
- Deposit money
- Withdraw money with validation
- Check balance
- View transaction history

## 🛠️ Technologies Used
- Java (Core Java)
- OOP Concepts
- ArrayList
- Eclipse IDE

## 🧠 Concepts Practiced
- Encapsulation
- Classes and Objects
- Methods
- Conditionals and Loops

## ▶️ How to Run
1. Open project in Eclipse
2. Run `ATMSystem.java`
3. Enter PIN and use menu options

## 📈 Future Improvements
- File handling for data storage
